# Разкрой и кантиране

Отвори `index.html` директно в браузър или го хоствай като статични файлове.

- `optimizer.js` – търсене на разкрой и план на резовете, без зависимост от браузъра
- `main.js` – интерфейс, ръчна редакция, запис на проекта
- `npm test` – проверки на оптимизатора
- `npm run build` – един самостоятелен файл в `dist/index.html`

Размерите в списъка са крайни, с кант. Размерът за рязане се смята автоматично.
